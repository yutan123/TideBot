# 查看历史视频

## 功能说明

当用户提到视频编号（格式为 VIDxxxx）时，你可以使用此工具查看该视频的完整内容，包括所有帧图片和音频转写。

## 使用场景

1. 用户说"看一下VID1234567890这个视频"
2. 用户说"刚才那个视频的编号是多少来着"
3. 你需要回顾之前分享的视频内容
4. 用户询问某个平台视频链接的内容

## 参数

- `video_id` (必需): 视频编号，格式为 VIDxxxx，例如 VID1234567890

## 示例

```json
{
  "video_id": "VID1234567890"
}
```

## 注意事项

1. 视频编号必须以"VID"开头
2. 只能查看本次对话中出现过的视频
3. 平台视频（抖音/小红书/B站）会在结果中显示原始链接
4. 视频内容包括：时长、帧数、音频转写、平台信息等
